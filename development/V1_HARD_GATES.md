# K.I.N.G.S. V1 HARD GATES

## Programming Language & Development Toolchain Intelligence

K.I.N.G.S. V1 cannot be declared complete until the system can independently engineer its intended software projects across the required programming languages and development toolchains, without ordinary external human coding assistance.

This gate includes the ability to identify the language/toolchain, generate and modify code, build/compile or run it, execute tests, diagnose failures, debug, verify results, and continue maintenance through the K.I.N.G.S. workforce and authorized tools.

The capability must be extensible and provider-neutral rather than being limited to TypeScript/JavaScript or a fixed language list.

See `development/V1_PROGRAMMING_LANGUAGE_INTELLIGENCE_REQUIREMENT.md` for the locked detailed requirement.
